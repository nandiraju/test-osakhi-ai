# Patient Page — Agent & Developer Guide

Static React + Vite site for **https://test.osakhi.ai**, deployed by GitHub Pages.
This folder is a normal git checkout of its GitHub repo — work here, commit, and push.

## Commands
```bash
npm install          # install dependencies
npm run dev          # local dev server
npm run build        # tsc + vite build + prerender static HTML into dist/
npm run preview      # serve the production build
```

## Deploy
Pushing to `main` triggers `.github/workflows/deploy.yml` (build -> GitHub Pages). No Jekyll (`.nojekyll`).
Git auth: `origin` is a clean HTTPS URL; use your own GitHub credentials (gh auth / credential helper / PAT).

## Structure
| Path | Purpose |
|---|---|
| `src/App.tsx`, `src/components/` | React UI |
| `src/data/siteConfig.ts` | Page list and copy used by the React app |
| `src/index.css` | Styles |
| `index.html` | Template; SEO block lives between `<!--seo-head-->` markers (do not duplicate) |
| `prerender-pages.json` | Per-page SEO head + static HTML injected at build (`scripts/prerender.mjs`) |
| `public/` | Static assets, `sitemap.xml`, `robots.txt`, `CNAME`, images |

## Adding a page
1. Add the page to `pages` in `src/data/siteConfig.ts`.
2. Add a matching entry (slug, headHtml, bodyHtml) to `prerender-pages.json` so it is pre-rendered for SEO.
3. Add its URL to `public/sitemap.xml`.
4. Keep one `<h1>`, a unique title/description, and a canonical URL per page.

## Working alongside the Site Launch Agent
The site agent may regenerate files listed under `generatedFiles` in `site-agent.json` when it re-runs.
**To keep your edits, add the file paths to `preserve` in `site-agent.json`** — the agent will never overwrite them.
New files you add (not generated by the agent) are always kept.

Do not commit `node_modules/` or `dist/`. GA4 tag and Search Console verification are managed by the site agent.
